# ImunoQuest

Jogo educacional 2D desenvolvido em **Unity (C#)** com o objetivo de ensinar conceitos de **biologia e imunologia** para estudantes do ensino médio de forma interativa e divertida.

> ⚠️ Repositório ainda com o nome antigo `biologia_top_down` — renomeação pendente.

📌 Sobre o projeto

O ImunoQuest coloca o jogador no papel de um agente do sistema imunológico, enfrentando desafios que representam processos biológicos reais (como resposta imune, patógenos e mecanismos de defesa do corpo), em formato de jogo top-down com combate e progressão.

O projeto foi apresentado na **Mostra de Jogos 2026 (UFV)** e é tema de um artigo científico publicado no **CBIE 2026** (Congresso Brasileiro de Informática na Educação), do qual sou autora.

🎮 Funcionalidades

- Sistema de combate contra chefes (boss arena) com portas e progressão de fases
- Arquitetura orientada a eventos (event-driven)
- Sistema de estatísticas persistente (singleton) para acompanhar o progresso do jogador
- Economia de ATP como recurso do jogo, balanceada para progressão
- Diálogos de NPCs para reforçar o conteúdo educacional
- Sistema de loja com preços balanceados

🛠️ Tecnologias

- Engine: Unity
- Linguagem: C#
- Plataformas de build: Windows, Linux e Android

## 🚀 Como rodar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/Myrella669/biologia_top_down.git
   ```
2. Abra o projeto no **Unity Hub**
3. Abra a cena principal em `Assets/Scenes/` e clique em Play
